# Pink WPF Calculator

Учебный проект приложения «Калькулятор» с графическим интерфейсом на платформе WPF (.NET Framework), рефакторенный под архитектурный паттерн **MVVM**.

## Назначение проекта
Выполнение базовых арифметических операций, вычисление процентов и работа с числами. Проект разделен на отдельные модули для независимой работы логики и интерфейса.

## Структура проекта и модулей

* **`Views/`** — Слой представления (UI). Содержит `MainWindow.xaml` и `MainWindow.xaml.cs`.
* **`ViewModels/`** — Модель представления. Содержит `MainViewModel.cs` для управления состоянием UI и командами (`ICommand`).
* **`Models/`** — Модель данных. Содержит `CalculatorModel.cs` с математической логикой и проверкой условий (деление на ноль).
* **`Services/`** — Сервисный слой. Содержит `IDialogService.cs` и `DialogService.cs` для отображения сообщений и ошибок.
* **`Infrastructure/`** — Базовые механизмы MVVM:
  * `BaseViewModel.cs` — реализация `INotifyPropertyChanged`.
  * `RelayCommand.cs` — реализация `ICommand`.
* **`Resources/`** — Ресурсы и стили оформления элементов управления.

## Запуск и сборка
1. Открыть `PinkWpfCalculator.sln` в **Visual Studio**.
2. Собрать решение (`Ctrl + Shift + B`).
3. Запустить проект (`F5`).
