## 3. Протоколы взаимодействия

### Протокол IDialogService
* Участники: `ViewModels` ➔ `Services`
* Назначение: Отображение пользовательских сообщений.
* Интерфейс: `void ShowMessage(string title, string message)`
* Формат данных: Строки C# (`string`).

### Протокол CalculatorModel
* Участники: `ViewModels` ➔ `Models`
* Назначение: Расчет математических выражений.
* Интерфейс: `double Calculate(double first, double second, string op)`
* Формат данных: Числа и строки C# (`double`, `string`).

## 4. Соглашения об именовании и версионировании
* Классы: PascalCase (`CalculatorModel`).
* Интерфейсы: Префикс `I` (`IDialogService`).
* Коммиты: `docs: add ARTIFACTS.md`.
* Версия: `v1.0.0` (SemVer).
